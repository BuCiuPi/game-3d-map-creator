06 · Risk controls

Những chỗ dễ xóa nhầm

High

Serialized GUIDs

Prefab/scene/material có thể compile sạch nhưng mất reference. GUID grep + Editor evidence là bắt buộc trước và sau mỗi move/delete.

High

VFX bundle fan-out

255 package entries và hard refs shader/material có thể kéo bundle hoặc tạo Missing Shader sau khi package biến mất.

Medium

Bootstrap coupling

Legacy boot hiện authenticate, build scopes và load lobby. Neutral boot phải thay luồng trước khi xóa assembly nguồn.

Medium

Tooling loss

Một số Addressables menus nằm trong legacy shared code. Chỉ giữ/rewrite tool thực sự cần; Python checker vẫn là proof độc lập.

Medium

Git UPM monorepo cost

Nhiều package con từ cùng Git repo khiến Unity clone repo nhiều lần. Chỉ thêm package cụ thể hoặc dùng private registry khi số package tăng.

Control

No speculative dependencies

Không thêm networking/common core trong cleanup. Recipe tồn tại nhưng dependency chỉ xuất hiện cùng feature sử dụng nó.
