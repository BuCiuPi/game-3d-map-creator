# Exec Plan

## Goal

Remove the unused mobile service integration as one dependency cohort while
leaving the neutral boot, data core, UI shell, and content pipeline unchanged.

## Scope

In scope:

- Delete Firebase, EDM4U, generated Maven, Firebase editor resources, and mobile plugin roots.
- Delete stale Android service manifests and Gradle/proguard templates with those roots.
- Remove IAP, Unity cloud-build/diagnostics/core packages and unused service registry scopes.
- Regenerate `packages-lock.json` through Unity.
- Extend the template boundary invariant and prove a normal fresh clone.

Out of scope:

- Art/content/editor plugin pruning.
- Platform builds, credentials, signing, or release profiles.

## Risk Classification

Risk flags (from `docs/FEATURE_INTAKE.md`):

- Serialized assets.
- Packages.
- Build profiles.
- Template boundary.
- Auth / SDKs.

Hard gates:

- Removing vendored plugins and package defaults inherited by derived projects.

## Work Phases

1. Freeze baseline commit `3467621` and dependency/GUID inventory.
2. Record decision `0010` and acceptance invariants.
3. Remove the complete service cohort and manifest entries.
4. Let Unity import, normalize platform flags, and regenerate the package lock.
5. Run compile, EditMode, boot, Addressables, and legacy-path scans.
6. Commit, then prove a normal fresh clone of that commit.
7. Record validation, trace, and any deferred platform evidence.

## Stop Conditions

Pause for human confirmation if:

- Any retained asset references one of the 145 cohort GUIDs.
- A template runtime assembly consumes a removed SDK or package.
- Removal changes an Addressables group, asset GUID, address, or boot behavior.
- Unity cannot resolve a normal clone without restoring a service dependency.
